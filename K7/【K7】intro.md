## 各题完成备注

### 1. 递归计算斐波那契数列
- 用朴素递归 `fib(n-1) + fib(n-2)` 实现，配合 `time.perf_counter()` 计时。
- 测试 n = 37、38、39、40，可观察到耗时呈指数级增长。
- **重复计算体现**：同一 `fib(k)` 在递归树中被反复计算多次，例如 `fib(5)` 会重复计算 `fib(3)`、`fib(2)` 等，子问题大量重叠，时间复杂度 O(2ⁿ)。

### 2. 艺术分形树
- 使用 `turtle` + `random` 递归绘制，满足全部四项要求：
  - 粗细随递归深度变细（`pensize = depth × 1.5`）；
  - 颜色按长度渐变：棕褐（主干）→ 橄榄绿 → 嫩绿 → 末端随机花/果色；
  - 倾斜角度在 15~45° 范围随机，左右独立；
  - 长度随机缩减为原长 0.65~0.85 倍；
- 额外加入 30% 概率的中间小分支，使树更茂密逼真。

### 3. 区分打包和元组参数
- 概念辨析题，采用「相同点 + 不同点 + 对比表 + 一句话总结」结构作答。
- 核心结论：`*args` 是「先散后聚」（调用时散着传、函数里聚成元组）；接收元组的形参是「聚着传、聚着用」。

### 4. 编写推导式
- 一行生成器表达式：`' '.join(str(len(word)) for word in input().split())`。
- 输入示例 `abc hello world` → 输出 `3 5 5`。

### 5. 编写推导式 + 聚合函数
- (1) 倒数之和：`sum(1 / i for i in range(1, 101))`。
- (2) 最长字符串：`max((len(s), s) for s in str_list)[1]`，借助元组比较（先比长度，长度相同再比字典序）取出最长串。

### 6. 100以内所有勾股数
- 一条三重循环列表推导式生成，强制 `i < j < k` 去重，结果共 52 组（含非本原勾股数如 (6,8,10)）。
- 推导式：`[(i, j, k) for i in range(1, 101) for j in range(i+1, 101) for k in range(j+1, 101) if i*i + j*j == k*k]`

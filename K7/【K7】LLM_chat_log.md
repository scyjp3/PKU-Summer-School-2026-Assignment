## 对话 2：第2题 · 艺术分形树

**我**：给我一个思路，第2题要做艺术分形树，还要加四个功能：粗细变化、颜色变化、角度随机、长度随机。

**AI**：好的，给你一个思路。整体框架用 `turtle` 模块递归绘制，核心是一个 `draw_tree(t, branch_len, depth)` 函数。

1. **递归终止条件**：当 `branch_len < 10` 或者 `depth <= 0` 就 return，否则：
   - 先向前画当前这截树枝 `t.forward(branch_len)`；
   - 向左转一个角度，递归画左子枝；
   - 回到原方向，再向右转一个角度，递归画右子枝；
   - 最后 `t.backward(branch_len)` 回到起点。

2. **四个功能分别对应哪里加代码**：
   - **粗细变化**：用 `t.pensize(...)`，参数和递归深度挂钩，比如 `depth * 1.5`，深度越深笔越细。
   - **颜色变化**：用 `t.pencolor(...)`，判断当前 `branch_len` 的长度区间：主干（>60）用棕色，中段用橄榄绿，末端（<30）用嫩绿色，最末端改成粉色或红色画花果。
   - **角度随机**：左右角度不要写死，用 `random.randint(15, 45)` 每次各生成一个，左右可以不一样。
   - **长度随机**：子枝长度不要固定乘 0.75，换成 `random.uniform(0.65, 0.85)` 就有随机效果。

3. 启动时把画笔移到画布底部中央 `goto(0, -250)`，朝向 90 度（朝上），背景色可以调个浅蓝像天空，效果更好。

## 对话 3：第3题 · 区分打包和元组参数

**我**：给我一个思路，第3题让我对比"打包的形参"和"接受元组的形参"在函数定义和调用上的异同，我该怎么组织答案？

**AI**：好的，给你一个思路。可以按这个结构写：

1. **先定义清楚两者分别是什么**：
   - 打包形参就是 `def f(*args):` 这种带 `*` 的，叫"可变位置参数"。
   - 接受元组的形参就是 `def f(t):` 这种普通形参，不过调用者传进来的是一个元组对象。

2. **相同点**想 2~3 条就够，比如：
   - 函数内部都能把数据当序列用（遍历、索引、求长度）。
   - 都能用 `*` 解包语法（但结果不一样，这点放到不同点里展开）。

3. **不同点**分"定义"和"调用"两个维度对比，最好做张表：
   - **定义语法**：一个有 `*` 前缀，一个是普通形参。
   - **调用时传几个参数**：`*args` 可以传 0 到任意多个位置参数，自动聚成元组；`t` 只能传恰好 1 个对象，否则报错。
   - **数据来源**：`*args` 的元组是解释器自动打的包，`t` 的元组是调用者自己构造好再传进去的。
   - **能不能不传**：`*args` 不传就是空元组 `()`，`t` 不传会报"缺少必填参数"（除非有默认值）。
   - **`f(*lst)` 解包的效果**：给 `*args` 用是"解包再打包"还是元组；给 `t` 用相当于传了多个位置参数，会报错参数个数不符。

4. **最后用一句话总结**它们的本质区别，比如"`*args` 是先散后聚，接收元组形参是聚着传聚着用"，这样老师一眼能看懂你理解了。

## 对话 7：第7题 · 生成无穷无尽的斐波那契数

**我**：给我一个思路，第7题要"编写一个生成器函数，能生成无穷无尽的斐波那契数列"。我知道要用 `yield`，但具体怎么写？

**AI**：好的，给你一个思路。

1. **生成器函数的骨架**：`def fibonacci():` 里面放一个 `while True:` 死循环，配合 `yield` 就能"暂停并产出一个值"。`while True` 不会让程序卡死，因为 `yield` 会把控制权还给调用者，只有 `next()` 才会继续跑下一轮。

2. **斐波那契的变量更新技巧**：维护两个变量 `a, b`，初始值都设成 1（如果课程定义首项是 0,1 也行，看你们教材，一般 K7 作业写 1,1 开始没问题）。
   - 每次 `yield a` 把当前值吐出去；
   - 然后用同步赋值 `a, b = b, a + b` 推到下一个数。
   - 这里的 `a + b` 用的是 yield 之前的老值，所以同步赋值是关键，不能拆开写。

3. **怎么用这个生成器**：
   - `fib_gen = fibonacci()` 只是创建对象，不会立即计算，是惰性的。
   - 要取数就用 `next(fib_gen)`，或者写个 `for _ in range(15): print(next(fib_gen), end=' ')` 取前 15 项演示。
   - 因为是无穷的，**千万不要**写 `for x in fibonacci()`，那会无限循环。

## 一、基本概念

### 1. 冯·诺依曼结构计算机
- **核心特点**："**存储程序**"（stored-program）
- **五大部件**：运算器、控制器、存储器、输入设备、输出设备
- **关键思想**：程序和数据以同等地位存放在同一个存储器中，机器能**自动按顺序**取指执行
- **普通计算器不符合**：缺少"存储程序"能力，依赖人工实时按键驱动

### 2. 三种基本控制结构

| 结构 | 关键字 | 特点 |
|---|---|---|
| **顺序结构** | （默认） | 语句从上到下依次执行 |
| **条件分支结构** | `if / elif / else` | 根据条件选择执行路径 |
| **循环结构** | `for / while` | 重复执行某段代码 |

### 3. 嵌套结构规则
- **任意两种（或多种）基本结构之间都可以相互嵌套**
- 顺序、条件分支、循环都可以作为"容器"包含其他结构

## 二、顺序结构

### 语句次序规则
- **有依赖关系**的语句：次序**不可调整**（后一条用到前一条的结果）
- **无依赖关系**的语句：次序**可以调整**（运行结果不变）

## 三、条件分支结构

### 1. if/elif/else 的顺序匹配特性
```python
if age < 0:
    print("输入有误")
elif age <= 6:      # 隐含 age >= 0
    print("童年")
elif age <= 17:     # 隐含 age > 6
    print("少年")
else:
    print("老年")
```
**简化技巧**：利用 elif 的顺序匹配，**无需写双向区间**（如 `0 <= age <= 6`）。

### 2. 红绿灯通行规则（8种情形）
- **左转**：左转灯绿(G) 或 左转灯灭(N)且直行灯绿(G)
- **直行**：直行灯绿(G) 或 直行灯灭(N)且(左转或右转灯绿)
- **右转**：右转灯绿(G) 或 右转灯灭(N)

## 四、循环结构

### 1. for 循环 vs while 循环

| 对比项 | for 循环 | while 循环 |
|---|---|---|
| **适用场景** | 已知循环次数 | 未知循环次数，靠条件终止 |
| **典型示例** | 走5个路口 | 走到丁字路口为止 |
| **关键字** | `for ... in range(...)` | `while 条件:` |

### 2. continue 语句
- **作用**：跳过本轮循环的剩余语句，直接进入下一轮
- **替代方法**：用 `if not 条件:` 反向判断，逻辑等价

```python
# 用 continue
for i in range(1, 21):
    if "7" in str(i):
        continue
    print(i)

# 不用 continue（等价写法）
for i in range(1, 21):
    if "7" not in str(i):
        print(i)
```

### 3. break 语句
- **作用**：立即跳出当前循环

### 4. 常见循环算法

#### 累加求和
```python
total = 0
for i in range(1, 1001):
    if i % 7 == 0:
        total += i
print(total)      # 输出 71071
```

#### 累乘（阶乘）
```python
fact = 1
for i in range(1, n + 1):
    fact *= i
```

#### 条件循环找阈值
```python
n, fact = 1, 1
while fact <= 100000000:    # 找超过1亿的阶乘
    n += 1
    fact *= n
# 结果：12! = 479001600
```

## 五、循环嵌套

### 1. 打印正方形
```python
for i in range(n):           # 外层控制行
    for j in range(n):       # 内层控制列
        print("*", end="")
    print()                  # 每行结束后换行
```

### 2. 打印三角形
```python
for i in range(1, n + 1):    # 外层控制行
    for j in range(1, i + 1):  # 内层列数 = 行号
        print("*", end="")
    print()
```

### 3. 判断素数
```python
for i in range(2, int(n**0.5) + 1):   # 只需判断到 √n
    if n % i == 0:
        print("no")
        break
else:                                   # for-else：循环正常结束才执行
    print("yes")
```

## 六、进度条（tqdm）

### 基本用法
```python
from tqdm import tqdm
import time

for i in tqdm(range(1, n + 1), desc="描述文字"):
    # 循环体
    time.sleep(0.2)          # 模拟耗时
```

### 动态更新描述
```python
pbar = tqdm(range(1, N + 1))
for i in pbar:
    # 循环体
    if i % 1000 == 0:        # 每1000次更新一次
        pbar.set_description(f"pi: {pi:.8f}")
```

## 七、异常处理

### 1. 常见异常类型

| 异常类型 | 触发条件 | 处理方法 |
|---|---|---|
| **ValueError** | `float()`/`int()` 转换非数字字符串 | 提示"请输入数字" |
| **ZeroDivisionError** | 除数为 0 | 提示"除数不能为0" |
| **TypeError** | 数据类型不匹配 | 确保类型转换后再运算 |
| **KeyboardInterrupt** | 用户按 Ctrl+C | 提示"程序已取消" |

### 2. try-except 结构
```python
try:
    # 可能出错的代码
    a = float(input("请输入数字："))
except ValueError:
    print("请输入有效的数字")
except ZeroDivisionError:
    print("除数不能为0")
```

### 3. 关键原则
- **把可能抛出异常的语句放在 try 块内部**
- 捕获异常后**循环要求重新输入**，而不是直接终止程序

## 八、"强壮"程序的要求

### 什么是强壮（Robust）的程序？
能够**正确处理各种异常输入和边界情况**，不会因用户错误操作而崩溃。

### 强壮程序的要素
1. **处理非法输入**（非数字、空输入）
2. **处理边界值**（负数、过大值）
3. **循环验证**（错误时要求重新输入）
4. **函数封装**（输入验证与业务逻辑分离）
5. **友好提示**（错误信息清晰易懂）

## 九、蒙特卡洛方法计算圆周率

### 原理
向单位正方形内随机撒点，统计落在四分之一圆内的比例：
$$\pi \approx 4 \times \frac{\text{圆内点数}}{\text{总点数}}$$

### 代码要点
```python
from random import random

N = 10_000_000       # 总点数（越多越精确）
c = 0                # 圆内点数计数
for i in range(1, N + 1):
    x, y = random(), random()
    if x * x + y * y < 1:    # 用平方比较，省去开根号
        c += 1
pi = (c / N) * 4.0
```

## 十、易错点提醒

1. **range(a, b)**：包含 a，**不包含** b（左闭右开）
2. **整数除法**：`//` 是整除，`/` 是浮点除法
3. **取余运算**：`i % 7 == 0` 判断能否被7整除
4. **for-else**：循环正常结束（未 break）才执行 else
5. **变量遮蔽**：避免用 `sum`、`list` 等内置函数名作变量
6. **字符串包含判断**：`"7" in str(i)` 判断数字是否含7
7. **input() 返回字符串**：需要 `int()` 或 `float()` 转换

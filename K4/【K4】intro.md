# 【K4】进阶数据类型作业说明

本次 K4 进阶数据类型作业共完成 22 道题，涵盖列表、元组、集合、字典等进阶数据类型。

## 作业过程记录

* 切片参数方向必须一致：步长为正时起点 ≤ 终点，步长为负时起点 ≥ 终点，否则返回空列表
* 避免查找抛 `ValueError` 的两种方法：`if x in list` 先判断，或 `try-except` 捕获异常
* 列表加法 `+` 不满足交换律（拼接顺序不同），列表乘法 `*` 满足交换律，且列表只能乘整数
* `sort()` / `reverse()` 是原地修改，返回 `None`，不能直接打印；`sort(reverse=True)` 排序后降序，`reverse()` 仅反转位置
* 空列表调用 `len()` / `sum()` 返回 `0`，调用 `min()` / `max()` 抛 `ValueError`
* 元组不可变，更新元素需"转列表 → 修改 → 转回元组"
* `A in B` 检查的是 A 是否是 B 的一个元素，不是子集关系；子集判断用 `A.issubset(B)` 或 `A <= B`
* Python 链式比较陷阱：`x in y == z` 会被解析为 `(x in y) and (y == z)`，需加括号明确优先级
* 对称差 = 并集 - 交集，即 `(A | B) - (A & B) == A.symmetric_difference(B)`
* 三维数组是列表的列表的列表，通过 `arr[层][行][列]` 访问
* 整数 `13` 和字符串 `'13'` 是完全不同的键，不能混用；字符串学号适合有前导零的情况
* `['姓名']['年龄']` 是错误的链式索引，同级字段应分开访问

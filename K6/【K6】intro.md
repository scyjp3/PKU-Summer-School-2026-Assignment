# K6 作业说明

## 作业概述
本作业为【K6】文件和函数章节练习，共 28 题，涵盖文件读写、编码、CSV/JSON、函数定义与参数等知识点。

## 作业过程备注

1. **环境准备**：作业在 Windows 11 上完成，使用 Python 3。第三方模块 `jieba` 通过清华镜像源 `pip install jieba -i https://pypi.tuna.tsinghua.edu.cn/simple` 安装成功。

2. **数据文件来源**：
   - `全唐诗.txt`（约 11MB）用于第 9、16 题词频分析，从微信接收文件复制到工作目录。
   - `SourceHanSansSC-Normal.otf`（约 16MB）用于第 3 题大文件分段复制演示。

3. **遇到的问题与解决**：
   - **第 6 题歌词记录本**：输入菜单选项时误输入完整文字"4. 退出"导致循环刷屏，后将判断改为只取输入首个字符解决。
   - **第 8 题调整分词**：jieba 默认分词"销售/部长/会开/到/了/半夜"不符合期望，通过 `add_word("销售部长")`、`add_word("开到了")` 调整为"销售部长/会/开到了/半夜"。
   - **第 9 题高频词**：白居易结果混入 `--` 标点，后增加"必须含汉字"过滤规则解决。
   - **PowerShell 执行策略**：系统禁用了 ps1 脚本，运行 Python 程序不受影响，但内联 `python -c` 偶有干扰，改用 `.py` 文件执行。

4. **知识点体会**：
   - 文件操作：`xt`/`at`/`wt`/`rb`/`wb` 模式的区别，`writelines()` 不自动换行需手动加 `\n`。
   - 编码：gb2312 字符集小不收录生僻字"仌"，gbk/utf-8 可正常编码。
   - 函数：选项参数（默认值）、实参三种形式、可变对象原地修改才有副作用、`return` 返回值。
   - 数据格式：CSV 是文本文件可用文本方式处理；JSON 用数组存多行歌词、每行一个字符串。

## 2 系统概述
### 2.1 系统简介
本系统为北京大学暑期学校"Python语言基础与人工智能应用"课程的作业提交 Web 前端应用，采用哈利波特魔法主题风格设计，通过对接教学管理服务 API 实现与后端服务器的数据交互，为学生提供账号登录、作业查询提交、成绩查看与数据统计等核心功能。用户通过浏览器访问本地部署的网站即可完成全部操作。

### 2.2 核心功能
- 账号登录与安全注销
- 个人基本信息查询（姓名、学号）
- 作业列表查询与筛选（全部 / 进行中 / 已截止 / 未提交）
- 作业详情查看与提交历史查询
- K系列作业文件提交（intro.md / content.pdf / LLM_chat_log.md）
- 作业成绩查询与评语查看
- 学习进度与成绩数据统计

### 2.3 技术架构
| 模块 | 技术选型 |
|------|----------|
| 前端开发语言 | HTML5 + CSS3 + JavaScript (ES6+) |
| 界面框架 | 原生 HTML + 自定义 CSS（哈利波特主题） |
| 图标库 | Font Awesome 6.4.0 |
| 字体 | Cinzel + MedievalSharp（Google Fonts） |
| 网络请求 | 原生 Fetch API |
| 数据存储 | localStorage（登录令牌持久化） |
| 数据可视化 | CSS 进度条 + 数字统计卡片 |
| 数据交互 | 教学管理服务 RESTful API（`https://pysummer.pkuai.cc/api/v1`） |

## 3 运行环境与安装部署
### 3.1 环境要求
#### 3.1.1 硬件要求
- 处理器：Intel Core i3 及以上
- 内存：4GB 及以上
- 硬盘：剩余可用空间 ≥ 100MB

#### 3.1.2 软件要求
- 操作系统：Windows 10/11、macOS 10.15+、Linux Ubuntu 20.04+
- Python 版本：Python 3.6 及以上（仅用于启动本地 HTTP 服务器）
- 浏览器：Chrome / Edge / Firefox 最新版（需支持 ES6+ 与 Fetch API）
- 网络环境：可正常访问教学管理服务 API 服务器（`https://pysummer.pkuai.cc`）

### 3.2 安装步骤
1. **解压程序包**  
   将提交的源代码压缩包解压至本地任意目录，解压后目录结构参考附录 A。

2. **配置系统参数**  
   系统的 API 服务器地址统一配置在 `js/api.js` 文件首行，默认已指向教学管理服务：
   ```javascript
   const API_BASE_URL = "https://pysummer.pkuai.cc/api/v1";
   ```
   如需更换服务器地址，修改该行即可，无需安装任何依赖。

> 说明：本系统为纯前端应用，无第三方依赖库，无需执行 `pip install`。

### 3.3 启动运行
本系统通过 Python 内置的 HTTP 服务器启动，提供以下两种方式：

**方式一：双击启动脚本（推荐，Windows 用户）**  
双击项目根目录下的 `启动网站.bat` 文件，将自动启动本地服务器。

**方式二：命令行启动**  
打开终端/命令提示符，进入程序根目录，执行：
```bash
python -m http.server 8000
```

启动成功后，在浏览器中访问：**http://localhost:8000**  
> 注意：命令行窗口需保持打开，关闭后网站将停止运行。

## 4 功能操作指南
### 4.1 账号登录与注销
#### 4.1.1 登录系统
1. 启动系统后，浏览器打开 `http://localhost:8000`，进入登录界面；
2. 登录页面顶部显示"北京大学暑期学校"大标题与"Python语言基础与人工智能应用"副标题；
3. 在对应输入框填写**学号（Student ID）**与**API密钥（API Secret）**；
4. 点击「提交任务」按钮，系统将向服务器发起身份验证；
5. 验证成功后自动跳转至个人主页；验证失败将在表单下方显示红色错误提示（账号错误、网络异常等），5 秒后自动消失。

> 注意：登录凭证由教学管理服务统一分配，API 密钥区分大小写。仅学生角色账号可登录本系统。

#### 4.1.2 注销账号
1. 在个人主页右上角导航栏找到「退出」按钮；
2. 点击后系统将清除本地登录令牌（localStorage）并返回登录界面。

### 4.2 个人信息查询
1. 登录成功后自动进入个人主页，导航栏右上角展示从服务器同步的个人信息；
2. 信息包括：欢迎语 + 姓名、学号；
3. 该信息仅支持查看，不可编辑修改。

### 4.3 作业信息管理
#### 4.3.1 查询作业列表
1. 登录后，个人主页"作业列表"区块自动拉取所有已发布的作业信息；
2. 每条作业展示：作业标题、作业说明、截止时间、满分、作业状态（进行中/已截止）、提交状态（含版本号与提交时间，迟交会标注红色提示）、已发布成绩（绿色高亮）；
3. 可通过列表上方筛选按钮按状态筛选：
   - 「全部」：显示所有作业
   - 「进行中」：仅显示状态为 published 的作业
   - 「已截止」：仅显示状态为 closed 的作业
   - 「未提交」：仅显示尚未提交的作业

**长题目展开/折叠**：对于说明文字超过 3 行的长作业（如 K3、K4、K5），系统默认折叠为 3 行显示，并在下方显示金色「展开」按钮。点击「展开」可查看完整说明，按钮文字变为「收起」；再次点击折叠。

#### 4.3.2 提交作业
1. 在作业列表中找到目标作业，点击「提交作业」按钮（仅进行中或允许迟交的作业显示此按钮）；
2. 跳转至提交页面，页面顶部展示作业信息（标题、截止时间、满分）；
3. 页面中部展示 **K系列作业提交格式说明**，包含 4 项规范；
4. 按格式要求分别上传文件：
   - **作业说明（intro.md）**：可在文本框直接输入，或点击/拖拽上传 `intro.md` 文件（对应 API 字段：`text`）
   - **作业内容（content.pdf）**：点击/拖拽上传 PDF 文件，支持格式 `.pdf / .txt / .py / .ipynb / .zip`（对应 API 字段：`file`）
   - **AI对话记录（LLM_chat_log.md）**：可选，点击/拖拽上传 `.md` 文件（对应 API 字段：`LLM_chat_log`）
5. 上传后文件以卡片形式展示，显示文件名、大小，可点击「打开」在新标签页预览文件内容，或点击「移除」取消上传；
6. 点击底部「提交作业」按钮，系统上传文件并返回提交结果；
7. 提交成功后显示绿色成功提示，包含版本号、提交时间、是否迟交，以及已提交文件清单；
8. 点击「返回作业列表」回到主页。

> 注意：
> - 至少需提供作业说明（text）或作业文件（file）之一方可提交；
> - 截止时间过后，仅允许迟交的作业可继续提交，并标记为"迟交"；
> - 同一作业可多次提交，每次提交版本号递增，以最后一次提交内容为准。

#### 4.3.3 查询作业提交记录
1. 在作业列表中点击某作业的「详情」按钮，进入作业详情页；
2. 详情页展示作业完整信息，包括标题、说明、截止时间、满分、作业状态；
3. 页面下方"提交历史"区块展示该作业的所有提交记录，包含版本号、提交时间、是否迟交、提交的文件清单；
4. 可查看已提交文件的原始文件名与大小。

### 4.4 作业成绩查询
1. 在个人主页"已发布成绩"区块，系统展示所有已批改并发布的作业成绩；
2. 每条成绩展示：作业名称、得分 / 满分（含百分比）、成绩发布时间；
3. 若教师填写了评语，将以金色边框区块展示评语内容；
4. 成绩数据由服务器实时同步，无需手动刷新。

### 4.5 成绩统计与数据展示
1. 个人主页顶部"学习进度"区块自动对学习数据进行统计分析，展示以下内容：
   - **四项核心指标卡片**：作业总数、已提交数、按时提交数、已评分数
   - **成绩统计区块**：
     - 总分（已得分数 / 总满分）
     - 平均分百分比
     - 完成进度条（已提交数 / 作业总数，金色进度条 + 百分比数字）

## 5 常见问题与故障排查
| 问题现象 | 可能原因 | 解决方法 |
|----------|----------|----------|
| 浏览器无法打开网站 | 本地 HTTP 服务器未启动 | 1. 双击 `启动网站.bat` 启动；2. 或在项目目录执行 `python -m http.server 8000` |
| 点击登录无响应/提示网络错误 | 网络不通、API 服务器不可达 | 1. 检查网络连接；2. 浏览器访问 `https://pysummer.pkuai.cc` 确认服务器可达 |
| 登录提示账号或密钥错误 | 学号/API密钥有误、大小写错误 | 核对学号与 API 密钥，注意区分大小写；联系教师确认账号状态 |
| 登录后跳回登录页 | 登录令牌丢失或过期 | 重新输入学号与 API 密钥登录即可 |
| 作业文件上传失败 | 文件格式不支持、网络波动 | 1. 确认文件格式在允许范围内（intro 仅 .md，content 支持 .pdf/.txt/.py/.ipynb/.zip）；2. 重试上传 |
| 拖拽文件无反应 | 拖拽位置不准确 | 改为点击上传区域选择文件，或确保文件拖入虚线框区域内 |
| 点击"打开"无法预览文件 | 浏览器拦截了弹窗 | 在浏览器地址栏右侧允许该站点弹出窗口后重试 |
| 个人主页数据显示异常 | 接口返回数据格式变动 | 按 `Ctrl + Shift + R` 强制刷新页面；如仍异常请重新登录 |
| 网站突然无法访问 | 命令行窗口被关闭导致服务器停止 | 重新执行启动命令，再次访问 `http://localhost:8000` |

## 6 创新点

1. **哈利波特魔法主题设计**：整套界面采用深紫蓝 + 魔法金的霍格沃茨配色，搭配 Cinzel / MedievalSharp 复古魔法字体，登录页配有悬浮羽毛笔动画，个人主页配有金色飞贼、漂浮蜡烛、猫头鹰羽毛、魔法闪烁星等动态装饰元素，营造沉浸式魔法学习氛围。

2. **K系列作业规范引导**：提交页面以编号卡片形式清晰展示 K 系列作业 4 项提交规范（创建文件夹、intro.md、content.pdf、LLM_chat_log.md），并用金/红/绿三色边框区分字段类型，降低学生提交错误率。

3. **长题目折叠展开**：作业列表中对超长说明自动折叠为 3 行并配渐变遮罩，仅显示"展开"按钮，兼顾信息密度与界面整洁。

4. **拖拽 + 点击双模式上传**：所有文件上传区同时支持拖拽与点击两种交互，拖入时金色高亮反馈；上传后文件以可点击卡片形式展示，支持在线预览（md 文本直接渲染、PDF 内嵌阅读器），无需下载即可查看。

5. **绕过系统对话框的文件预览**：通过同步打开新窗口 + document.write 的方式预览文件，巧妙绕过 Windows "打开方式"弹窗，提升体验流畅度。

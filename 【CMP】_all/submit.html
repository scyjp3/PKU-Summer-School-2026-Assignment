K系列作业提交格式

请按照以下格式提交您的K系列作业：

  1. 1、
    创建作业文件夹
    为每个K系列作业创建单独的文件夹，名称为K0、K1、K2等
  2. 2、
    intro.md
    作业说明文件，包含作业的详细说明和完成情况
    对应字段: text
  3. 3、
    content.pdf
    作业内容文件，由content.md生成的PDF文档
    对应字段: file
  4. 4、
    LLM_chat_log.md
    AI对话记录文件，记录您与AI的交互过程
    对应字段: LLM_chat_log

## 3 运行环境与安装部署
### 3.1 环境要求
#### 3.1.1 硬件要求
- 处理器：Intel Core i3 及以上
- 内存：4GB 及以上
- 硬盘：剩余可用空间 ≥ 500MB

#### 3.1.2 软件要求
- 操作系统：Windows 10/11、macOS 10.15+、Linux Ubuntu 20.04+
- Python 版本：Python 3.8 及以上
- 网络环境：可正常访问教学管理服务 API 服务器

### 3.2 安装步骤
1. **解压程序包**  
   将提交的源代码压缩包解压至本地任意目录，解压后目录结构参考附录 A。

2. **安装依赖库**  
   打开终端/命令提示符，进入程序根目录，执行以下命令安装依赖：
   ```bash
   pip install -r requirements.txt
   ```

3. **配置系统参数（可选）**  
   打开 `config.py` 或配置文件，确认 API 服务器地址、端口等参数与实际环境一致：
   ```python
   API_BASE_URL = "http://【服务器地址】:【端口】/api"
   ```

### 3.3 启动运行
- **桌面应用**：双击运行 `main.py`，或在终端执行：
  ```bash
  python main.py
  ```
- **Web 应用**：执行启动命令后，在浏览器中访问提示的本地地址（如 `http://127.0.0.1:5000`）。

## 4 功能操作指南
### 4.1 账号登录与注销
#### 4.1.1 登录系统
1. 启动系统后，进入登录界面；
2. 在对应输入框填写**用户名**与**登录密码**；
3. 点击「登录」按钮，系统将向服务器发起身份验证；
4. 验证成功后自动跳转至系统主界面，验证失败将弹出错误提示（用户名/密码错误、网络异常等）。

> 注意：请确保网络连接正常，登录凭证由教学管理服务统一分配。

#### 4.1.2 注销账号
1. 在系统主界面右上角/菜单栏找到「注销」按钮；
2. 点击后确认退出操作，系统将清除本地登录状态并返回登录界面。

### 4.2 个人信息查询
1. 登录成功后，在左侧导航栏/顶部菜单点击「个人信息」入口；
2. 页面将展示从服务器同步的个人信息，包括姓名、学号、班级、专业等字段；
3. 该页面仅支持查看，不可编辑修改。

### 4.3 作业信息管理
#### 4.3.1 查询作业列表
1. 点击导航栏「作业管理」→「作业列表」；
2. 系统自动拉取所有已发布的作业信息，展示作业名称、发布时间、截止时间、作业状态（未提交/已提交/已截止）；
3. 可通过搜索框按作业名称筛选，或按截止时间排序。

#### 4.3.2 提交作业
1. 在作业列表中选中目标作业，点击「提交作业」按钮；
2. 在弹出的提交窗口中，点击「选择文件」，选择本地作业文件（支持格式：【填写如 .py / .zip / .pdf 等】）；
3. 可在备注框中填写作业说明（可选）；
4. 点击「确认提交」，系统上传文件并返回提交结果；
5. 提交成功后，作业状态自动更新为「已提交」。

> 注意：截止时间过后无法提交作业；同一作业可多次提交，以最后一次提交内容为准。

#### 4.3.3 查询作业提交记录
1. 在「作业管理」菜单中点击「提交记录」；
2. 页面展示所有已提交作业的记录，包含作业名称、提交时间、提交文件名、提交状态；
3. 点击单条记录可查看提交详情，支持下载已提交的作业文件。

### 4.4 作业成绩查询
1. 点击导航栏「成绩管理」→「成绩查询」；
2. 系统展示所有已批改作业的成绩信息，包含作业名称、满分、得分、批改状态、评语；
3. 支持按课程、作业名称、成绩区间进行筛选查询。

### 4.5 成绩统计与可视化
1. 点击导航栏「成绩统计」进入可视化页面；
2. 系统自动对所有作业成绩进行统计分析，展示以下图表：
   - 各次作业得分趋势折线图
   - 成绩分布柱状图/饼图（优秀、良好、及格、不及格占比）
   - 个人平均分、最高分、最低分等核心指标
3. 可切换统计维度（按学期、按课程），图表支持缩放、导出为图片。

## 5 常见问题与故障排查
| 问题现象 | 可能原因 | 解决方法 |
|----------|----------|----------|
| 点击登录无响应/提示网络错误 | 网络不通、API 地址配置错误 | 1. 检查网络连接是否正常；2. 确认 config.py 中 API 地址与端口正确 |
| 登录提示用户名或密码错误 | 账号信息有误、大小写错误 | 核对账号密码，注意区分大小写；联系管理员确认账号状态 |
| 作业文件上传失败 | 文件过大、格式不支持、网络波动 | 1. 检查文件大小是否超出限制；2. 确认文件格式在允许范围内；3. 重试上传 |
| 成绩图表不显示 | 可视化库未安装、无成绩数据 | 1. 确认 matplotlib/echarts 等依赖安装成功；2. 确认存在已批改的作业成绩 |
| 程序启动报错 | Python 版本不兼容、依赖缺失 | 1. 检查 Python 版本 ≥ 3.8；2. 重新执行 `pip install -r requirements.txt` |

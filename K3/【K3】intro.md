# 【K3】数据类型思考题作业说明

## 作业概述

本次作业为【K3】数据类型思考题，主要涉及 Python 基本数据类型的应用与实践，包括字符串处理、数值运算、布尔类型判断、海龟作图以及 OJ 编程练习等内容。

## 作业过程中的备注

1. **问题3**：通过 `float()` 动态生成浮点数绕过 Python 常量折叠优化，成功验证了"值相等不一定是同一对象"。

2. **问题7**：使用 `find()` 方法定位关键字位置，需要注意加上关键字长度才能跳过前缀提取实际内容。

3. **问题12**：原代码误用 `bool(input())` 判断 VIP 身份，由于非空字符串的 `bool()` 值均为 True 导致逻辑错误，已改用字符串比较修复。

4. **问题14（海龟作图）**：14.6 三角警示牌通过 `n * 比例` 的方式设置所有元素尺寸，保证图形在 n=100~300 范围内不变形。

5. **问题19（OJ）**：OJ 提交时 `input()` 不能带提示文字，且苹果与虫子问题需使用整除 `//` 计算被吃掉的苹果数。

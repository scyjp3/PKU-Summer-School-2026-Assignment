# Peking University Summer School 2026
## Python Programming & AI Application Projects

This repository contains all coursework completed during the **Peking University Summer School** program for the course **"Python Language Fundamentals and Artificial Intelligence Applications"** (Python语言基础与人工智能应用).

The coursework spans a progressive series of assignments (K0–K7), a comprehensive programming project (CMP), a Harry Potter–themed assignment submission website, and a final group project (FindMyLab).

## Learning Outcomes

- Mastered Python fundamentals: data types, control flow, functions, file I/O, and recursion.
- Applied number-system conversions (decimal/binary/octal/hex) and Unicode/UTF-8 encoding analysis.
- Analyzed multimedia file formats (MP3, MIDI, PNG/JPG, MP4) and computed compression ratios.
- Developed a full-stack web application (Flask + HTML/CSS/JS) integrating a RESTful API with token authentication.
- Practiced AI-assisted programming throughout, using LLMs to generate, debug, and document code.
- Automated PDF report generation with `reportlab`, `playwright`, and `pygments`.
